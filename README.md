# Sensorchina

## Local Preview

Run a one-command preview server from the repository root:

```bash
./preview.sh
```

Optional custom port:

```bash
./preview.sh 9000
```

Then open one of these pages:
- `http://localhost:8080/en/`
- `http://localhost:8080/en/length/cm-to-inches/`
- `http://localhost:8080/zh-cn/length/cm-to-inches/`
- `http://localhost:8080/fr/length/cm-to-inches/`
